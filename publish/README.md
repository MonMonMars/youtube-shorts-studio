# Publish

Metadata and checks before a Short goes live.

- **`PUBLISH-PACK-TEMPLATE.md`** — title, description, hashtags, links, disclosures.
- **`POSTING-CHECKLIST.md`** — quick checkbox upload steps in YouTube Studio.
- **`POSTING-SOP.md`** — full post flow (export names → title → description → pin → first hour).
- **`FILM-WEEK-POST-PACK.md`** — ready-to-paste packs for [`calendar/FILM-THIS-WEEK.md`](../calendar/FILM-THIS-WEEK.md) (week 1 · 7 Shorts).
- **`FILM-WEEK-2-POST-PACK.md`** / **`FILM-WEEK-3-POST-PACK.md`** / **`FILM-WEEK-4-POST-PACK.md`** — weeks 2–4 (see [`30-DAY-PLAN.md`](../calendar/30-DAY-PLAN.md)).
- **`TITLE-PACK.md`** / **`DESCRIPTION-CTA.md`** — reusable title and CTA blocks.

Save one publish pack per Short; paste the public URL when live.
