# Posting checklist (YouTube Studio)

Use with **`PUBLISH-PACK-TEMPLATE.md`** for each Short.

## Upload

- [ ] Correct Google account / channel selected
- [ ] Video file uploaded (vertical Short)
- [ ] Title from publish pack pasted and reviewed
- [ ] Description from publish pack pasted
- [ ] Hashtags in description (not stuffed in title unless intentional)

## Shorts & delivery

- [ ] `#Shorts` present per your strategy
- [ ] Captions: auto OK or custom uploaded
- [ ] “Altered content” / synthetic media labels set if required
- [ ] Audience: not made for kids (unless it is)

## Legal & money

- [ ] Copyright checks passed in Studio
- [ ] “Paid promotion” toggled if sponsored
- [ ] Links in description tested

## Go live

- [ ] Visibility: public or scheduled
- [ ] Publish / schedule confirmed
- [ ] URL copied into publish pack
- [ ] Optional: pin comment, share to community tab

## After publish

- [ ] Add URL to idea/script front matter if you track links there
- [ ] Calendar reminder to fill `analytics/METRICS-TEMPLATE.md` (e.g. +72h)
