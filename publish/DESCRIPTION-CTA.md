# Description blocks & pinned-comment CTAs

Reusable YouTube Short **description** snippets and **pinned comment** templates. Replace `[BRACKETS]`. Verify links before publish. No income guarantees.

---

## Description — follow / series subscribe

```text
Building monetization-aware Shorts systems in public—hooks, offers, and honest policy notes.

Follow for [SERIES NAME] part [N+1].

Not financial or legal advice. Verify YouTube Partner Program and advertiser-friendly rules in YouTube Studio / Help.
```

**Short variant (under character budget):**

```text
Follow for part [N+1] of [SERIES NAME]. Monetization-aware Shorts—no fake earnings flex.
```

---

## Description — link in bio / product (soft)

```text
[PRODUCT NAME] — [one honest line: stage, e.g. early build / beta when ready / book in progress].

Link in bio when live: [URL or “coming soon—follow for updates”]

I may earn from links marked affiliate; always disclosed on-screen and here.
```

**Spark example (swap when beta exists):**

```text
Spark — dating app build log (MonMonMars/spark). Beta link in bio only when it’s real—follow Spark Lab for now.
```

**Companion / Robot Face / AI Video:** same shape—stage line + no fake launch claims.

## Description — comment prompt (lead gen without hard link)

```text
Comment **[KEYWORD]** if you want [what you’ll deliver: checklist shape / outline / next episode topic list].

I reply with [DM / community post / pinned follow-up]—no spam, one keyword only.

Tools mentioned: [names]. Affiliate/disclosure if applicable: [yes/no + #ad].
```

## Description — series “part N”

```text
[SERIES NAME] — Part [N] of [TOTAL or “ongoing”]

Today: [one-line episode summary]

Part [N-1]: [optional title or “see playlist”]
Part [N+1]: [tease one line—no fake cliffhanger outcomes]

Playlist: [URL when exists]
```
