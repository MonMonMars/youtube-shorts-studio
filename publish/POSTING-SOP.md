# Posting SOP — one Short, end to end

Standard flow from **master export** → **live on YouTube** → **first-hour engagement**. Use with [`FILM-WEEK-POST-PACK.md`](FILM-WEEK-POST-PACK.md) or [`PUBLISH-PACK-TEMPLATE.md`](PUBLISH-PACK-TEMPLATE.md). Quick checkbox version: [`POSTING-CHECKLIST.md`](POSTING-CHECKLIST.md).

Voice and compliance: [`../channel/BRAND-VOICE.md`](../channel/BRAND-VOICE.md).

---

## 0. Before Studio (export → pack)

1. Confirm master file name matches [`calendar/BATCH-DAY-RUNBOOK.md`](../calendar/BATCH-DAY-RUNBOOK.md):

   ```text
   YYYY-MM-DD_<script-slug>_master_v1.mp4
   ```

2. Run [`production/PRODUCTION-CHECKLIST.md`](../production/PRODUCTION-CHECKLIST.md) once on phone (captions, safe zone, audio).
3. Open the publish pack for this script; paste **export path** into internal notes (keep exports out of git).

---

## 1. Upload (YouTube Studio → Create → Upload video)

- [ ] Correct **channel** selected (brand account).
- [ ] Upload **`_master_v1.mp4`** (vertical 9:16).
- [ ] While processing: draft title/description in pack—don’t publish until checks pass.

---

## 2. Title

- [ ] Paste **primary title** from publish pack (≤ ~100 characters; front-load topic keywords).
- [ ] Match [`publish/TITLE-PACK.md`](TITLE-PACK.md) / script promise—no bait-and-switch.
- [ ] Series: include **pt N** in title when applicable (`Spark Lab pt 2`, `Companion Build pt 2`).
- [ ] Alt titles stay in pack for **A/B later**—don’t rotate title in first 72h unless typo.

---

## 3. Description

Paste in this order (from pack):

1. **Hook line** (first 2 lines visible above fold).
2. **Body** (episode summary, one insight, or series context).
3. **Links** (only live URLs; “follow for updates” if not live).
4. **Disclosures** (affiliate, paid promo, your product).
5. **Compliance block** when money/policy touched (from [`DESCRIPTION-CTA.md`](DESCRIPTION-CTA.md)).
6. **Hashtags** (3–5 max at end—see pack).

- [ ] `#Shorts` included per channel convention (description is fine).
- [ ] No stuffed hashtags in title unless intentional test.

---

## 4. Hashtags & keywords (discovery)

- [ ] Use pack **hashtag set** (3–5 tags).
- [ ] Add **one** niche tag max for product lanes (`#IndieApp`, `#BuildInPublic`, etc.)—not all at once.
- [ ] Spoken keywords in video should appear in description naturally (monetization, Spark, companion)—no keyword spam blocks.

---

## 5. Shorts-specific settings

- [ ] **Captions:** upload SRT or accept auto; fix proper nouns (Spark, Companion, YouTube Studio).
- [ ] **Altered content / synthetic media:** set if AI voice, avatar, or generative footage used.
- [ ] **Audience:** not made for kids (unless it is).
- [ ] **Recording date** (optional): set if batch-filmed earlier than publish week.

---

## 6. End screen, related, playlist (Shorts limits)

Shorts end screens differ from long-form—still set what Studio allows:

- [ ] **Related video:** point to **same series pt 1** or **monetization literacy** sibling when relevant.
- [ ] **Playlist:** add to series playlist (Spark Lab, Shorts Money, etc.) from [`channel/SETUP-CHECKLIST.md`](../channel/SETUP-CHECKLIST.md).
- [ ] **Pinned comment** drafted in pack—publish video first, then pin within 5 minutes.

---

## 7. Legal & money

- [ ] Copyright check passed in Studio (music, stock, UI captures blurred as planned).
- [ ] **Paid promotion** toggled ON if sponsored.
- [ ] **Ad-friendly self-check** done if discussing money/policy (see script + [`3-second-monetization-check.md`](../content/scripts/3-second-monetization-check.md)).
- [ ] Test every link in description on mobile.

---

## 8. Visibility & publish

- [ ] **Public** or **scheduled** (timezone noted in pack).
- [ ] Confirm **Shorts preview** looks correct (first frame = intended hook text safe zone).
- [ ] Copy **live URL** back into publish pack + optional script front matter.
- [ ] Update [`content/scripts/INDEX.md`](../content/scripts/INDEX.md) film/publish status.

---

## 9. Pinned comment (within 5 min of live)

- [ ] Paste **pinned comment** from pack (follow / series / keyword).
- [ ] If **comment keyword** CTA: pin the *fulfillment* reply template or first manual reply (“Replying with the layout—check pinned”).
- [ ] Pin only **one** comment; edit typos—don’t swap CTA in hour one.

---

## 10. First-hour engagement checklist

Goal: signal quality conversation, not spam.

| Time | Action |
| --- | --- |
| 0–15 min | Pin comment; heart 5–10 substantive comments (questions > “first!”) |
| 15–45 min | Reply to **keyword** comments you can fulfill manually; note count for analytics |
| 45–60 min | Reply to 3 policy/product questions with **verify in Studio** or honest WIP stage |
| Optional | Share unlisted-style tease on Community tab **if enabled**—link the Short URL |

Do **not** in hour one:

- Edit title/description repeatedly (hurts early signal interpretation).
- Paste link dumps in every reply.
- Promise earnings outcomes to keyword commenters.

---

## 11. After 72 hours

- [ ] Copy real Studio numbers into [`analytics/METRICS-TEMPLATE.md`](../analytics/METRICS-TEMPLATE.md)—no invented stats.
- [ ] Run [`analytics/WEEKLY-REVIEW.md`](../analytics/WEEKLY-REVIEW.md) when the week’s batch is live.
- [ ] Promote winning hook phrasing to [`content/hooks/README.md`](../content/hooks/README.md) if validated by retention.
