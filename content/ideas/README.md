# Ideas

Backlog for YouTube Shorts before scripting.

- Copy **`IDEA-TEMPLATE.md`** for each new concept.
- Name files `YYYY-MM-short-slug.md` so they sort by time.
- When an idea is approved, link to its script file in `content/scripts/`.
- Optional product lanes (founder Shorts): **`PRODUCT-SERIES.md`** — maps Mon’s projects to pillars without fake metrics.

Prioritize ideas that match your niche, are ad-friendly if you monetize with ads, and have a clear hook direction.
