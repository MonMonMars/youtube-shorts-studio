# Hooks

Reusable opening lines and patterns for Shorts. Copy winners from published scripts or add variants to test.

Keep hooks **specific** to a topic when possible; generic hooks burn out fast.

## Library

Add entries below or in separate files `hook-topic-slug.md`.

| Hook line | Topic / niche | Result (link to analytics) | Notes |
| --- | --- | --- | --- |
| _example: “Stop doing X if you want Y”_ | _topic_ | _pending_ | _tested YYYY-MM_ |

## Patterns that fit Shorts

- Contrarian: “Everyone says X. Do Y instead.”
- Specific outcome: “This one change fixed …”
- Curiosity gap: “Nobody talks about …”
- Visual first: show the result before explaining.

Update this table only with **real** post-publish notes from `analytics/`.
