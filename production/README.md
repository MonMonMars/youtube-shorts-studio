# Production

Templates for shooting and editing Shorts (9:16).

- **`PRODUCTION-CHECKLIST.md`** — prep, record, edit, export, compliance.
- **`AI-PIPELINE.md`** — Path A (film yourself), B (AI restyle), C (faceless / motion).
- **`SOURCE-CLIP-BRIEF.md`** — what to capture for each film-week Short (edit + AI source).
- **`EXPORT-SPECS.md`** — pre-upload Shorts export checklist.
- **`THUMBNAIL-TEXT.md`** — on-screen hook text for film-week Shorts (9:16 safe zones).
- **`B-ROLL-SHOT-BANK.md`** — reusable B-roll shot IDs.
- **`SHOT-LIST-TEMPLATE.md`** — planned shots and overlays per script.

Copy templates for each Short; store exports outside git unless you adopt LFS later.
