# Offer map template (Short → offer → CTA → tracking)

Copy a row per Short. Use **real** URLs and tracking IDs when you publish—leave placeholders until then.

## How to use

1. Pick pillar from `content/ideas/PILLARS.md`.
2. Choose **one primary monetization path** from `monetization/PLAYBOOK.md`.
3. Fill a row below (or duplicate this table in a dated file, e.g. `monetization/offer-map-2026-10.md`).
4. Mirror the CTA in `content/scripts/` and `publish/PUBLISH-PACK-TEMPLATE.md`.
