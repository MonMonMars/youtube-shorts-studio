# Weekly review checklist

Use once per week on **review day** (see [`calendar/30-DAY-PLAN.md`](../calendar/30-DAY-PLAN.md)). Tie **real** YouTube Studio data to hooks, pillars, and next week’s shoot list. No invented numbers—blank fields stay blank until Studio has data.

---

## Before you start

- [ ] Every Short published this week has a copy of [`METRICS-TEMPLATE.md`](METRICS-TEMPLATE.md) started (URL + publish date minimum).
- [ ] Wait until Studio shows meaningful retention (often 48–72+ hours after publish)—mark early files `pending` instead of guessing.
- [ ] Open Studio → **Analytics** → filter **Shorts** for the review window only.

---

## Step 1 — Pull metrics (placeholders → facts)

For each Short this week, copy from Studio into its metrics file:

| Studio field | Metrics template row | If empty / pending |
| --- | --- | --- |
| Views | Views | Skip compare; note “too early” |
| Average percentage viewed | Retention | Still note hook feel qualitatively |
| Impressions + CTR | Impressions, CTR | CTR only when impressions exist |
| Estimated revenue (if monetized) | Revenue section | Leave blank if not in YPP / no ads |
| Comments (count) | Likes / comments | Use for keyword CTA tests only |

**Channel-level (optional):** subscribers gained this week, top traffic source—write in one line at the bottom of this checklist, no benchmarks unless you have prior weeks logged.

---

## Step 2 — Score hooks (keep / tweak / replace)

| Question | Action |
| --- | --- |
| Retention **above** your recent median for the pillar? | **Keep** hook pattern—add exact line to [`content/hooks/README.md`](../content/hooks/README.md) or STARTER promotion note |
| Drop in first **3 seconds**? | **Tweak**—re-film hook only; compare to [`hook-that-pays-rent.md`](../content/scripts/hook-that-pays-rent.md) structure |
| Mid-video cliff? | **Tweak** body—one beat rule; check script length |
| Comments on keyword but no pin clicks? | **Tweak** fulfillment—pinned comment clarity, not new hook |

Do **not** declare a winner without retention or view data—use qualitative “felt rushed” notes sparingly and label them **subjective**.

---

## Step 3 — Map pillars → double down

Cross-reference each Short’s pillar ([`PILLARS.md`](../content/ideas/PILLARS.md)) with metrics:

| Pillar | Double down when… | Pull back when… |
| --- | --- | --- |
| **Monetization literacy** | Strong retention + policy-safe comments; revenue row filled honestly | Policy confusion in comments—film clearer rewrite Short |
| **Offer architecture** | Keyword comments ↑; subscribers gained on CTA Shorts | CTA Shorts with low retention—mid-CTA pattern from script #3 |
| **Retention mechanics** | Above-median % viewed on hook-teaching Shorts | Hook Shorts underperform—batch film 5 variants next batch day |
| **Batch & systems** | Saves / shares (if visible) or repeat requests for templates | Low views but high retention—distribution tweak, not script dump |
| **Proof without flex** | Trust comments; series follow-through | Any temptation to add income screenshots—stay process-first |

**Product lanes** ([`PRODUCT-SERIES.md`](../content/ideas/PRODUCT-SERIES.md)): rotate weekly; double down on the lane with **engaged comments** (not view count alone). Log **Part N** in publish pack for continuity.

---

## Step 4 — Decide what to film next week

Fill this table from Step 2–3—concrete scripts, not vague goals.

| Slot | Suggested source | Script file (pick one) | Why |
| --- | --- | --- | --- |
| Short 1 | Backlog gap or winning pillar | | |
| Short 2 | Backlog gap or winning pillar | | |
| Short 3 | Product lane rotation | | |
| Short 4 | Hook test / batch filler | `five-hooks-you-can-film-today.md` or STARTER-HOOKS | |
| Batch reserve | Film hooks-only block | [`BATCH-DAY-RUNBOOK.md`](../calendar/BATCH-DAY-RUNBOOK.md) | |

**Rules:**

- At least **2× monetization pillar** Shorts from backlog when channel is growth-focused.
- **1× product lane** Short per week unless metrics say pause (then one proof-without-flex backlog instead).
- If **no Short** has retention data yet, film **backlog #5 or #9** (systems) + one **founder lane** script—build library before optimizing.

---

## Step 5 — Offer map & compliance sanity check

- [ ] Update [`monetization/OFFER-MAP.md`](../monetization/OFFER-MAP.md) rows for any new keyword or link—placeholders OK until live.
- [ ] Pinned comments match on-screen disclosures (#ad, affiliate, not legal advice).
- [ ] No new income or ranking claims slipped into scripts during the week.

---

## Step 6 — Archive & handoff

- [ ] Move completed metrics files to a dated folder or naming convention you prefer (keep in repo if small).
- [ ] One sentence **week summary** (optional): what to repeat, what to stop—store at top of next week’s first metrics file.
