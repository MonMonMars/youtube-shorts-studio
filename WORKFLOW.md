# YouTube Shorts workflow

End-to-end path from idea to metrics review. Use the linked templates in each folder; copy a template file when starting a new Short rather than editing the master copy.

## Overview

```text
Idea → Script → Produce → Publish → Review metrics → Feed back into ideas
```

| Stage | Folder | Primary output |
| --- | --- | --- |
| Capture & prioritize | `content/ideas/` | Ranked idea entry |
| Write for retention | `content/scripts/` | Finished script + length target |
| Open strong | `content/hooks/` | Hook line(s) tied to script |
| Shoot & edit | `production/` | Completed checklist + shot list |
| Go live | `publish/` | Title, description, hashtags, posting checklist |
| Learn | `analytics/` | Per-Short metrics notes |

---

## 1. Idea

1. Add a row or copy `content/ideas/IDEA-TEMPLATE.md` into a new file (e.g. `content/ideas/2026-10-topic-slug.md`).
2. Fill in: audience pain, angle, monetization tie-in (ad-friendly topic, affiliate, lead magnet, etc.), and rough hook direction.
3. Score or tag priority (see template). Move “ready to script” ideas to the top of your backlog.

**Exit criteria:** One clear angle, target viewer, and why this Short is worth making now.

---

## 2. Script

1. Copy `content/scripts/SCRIPT-TEMPLATE.md` to a new file named after the working title.
2. Write **hook first** (first 1–3 seconds on paper). Pull from or add to `content/hooks/` if reusable.
3. Body: one main beat; cut anything that doesn’t serve retention or the CTA.
4. Set a **length target** (often 30–45s or under 60s). Read aloud and trim.
5. End with a **CTA** aligned with monetization (subscribe, link in bio, product mention policy, etc.).

**Exit criteria:** Hook, body, CTA, and length target filled; read-through under target time.

---

## 3. Produce

1. Copy `production/PRODUCTION-CHECKLIST.md` and `production/SHOT-LIST-TEMPLATE.md` for this Short.
2. Plan shots (A-roll, B-roll, text overlays, captions).
3. Record vertical (9:16), safe zones for UI/captions, clean audio.
4. Edit: hook in first frame; captions; pacing; export per your channel specs.
5. Check ad-friendly / music / disclosure requirements before publish.

**Exit criteria:** Checklist complete; master export ready; no open legal/music issues.

---

## 4. Publish

1. Copy `publish/PUBLISH-PACK-TEMPLATE.md` for this Short.
2. Draft **title** (search + curiosity), **description** (keywords + links/disclosures), **hashtags** (mix of broad + niche).
3. Run `publish/POSTING-CHECKLIST.md`.
4. Upload to YouTube Shorts; schedule or publish; note URL and date in the publish pack.

**Exit criteria:** Live (or scheduled) with metadata saved in `publish/`.

---

## 5. Review metrics

1. After meaningful data (often 48–72h+; longer for smaller channels), copy `analytics/METRICS-TEMPLATE.md`.
2. Record **views**, **average view duration / retention**, **CTR** (if available from Studio), and **revenue or monetization notes** only from real YouTube Studio data—do not invent numbers.
3. Write one “keep / change / kill” note for hook, pacing, and CTA.
4. Move learnings into the next idea or hook library entry.

**Exit criteria:** Template filled with actual numbers or “pending / not enough data”; at least one actionable note.

---

## Cadence suggestions

- **Batch ideas** weekly; **script** in focused blocks; **produce** in batches for consistent lighting/setup.
- Reuse hooks that worked; retire hooks that repeatedly underperform (per your analytics notes).
- Keep monetization constraints in mind early (brand-safe topics, disclosures, platform policies).
