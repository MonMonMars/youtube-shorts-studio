# YouTube channel setup checklist (Shorts-first)

Use once when launching or refreshing **Mon Mon**’s channel. Check boxes only—no subscriber or revenue claims required. Re-verify monetization and Community tab availability in YouTube Studio (features vary by account and region).

---

## Account & identity

- [ ] Correct Google account owns the channel (brand vs personal decided)
- [ ] **Channel name** matches how you say it on Shorts (consistent with Spark / Companion / book mentions)
- [ ] **Handle** (@…) is short, memorable, and matches bio links when live
- [ ] **Profile photo:** readable at tiny size (face or simple mark—not busy detail)
- [ ] **Banner:** note for design—safe text in center “TV” crop; avoid critical copy at edges (mobile crops aggressively). Suggested message: *Monetization-aware Shorts + build-in-public* (no income screenshots)
- [ ] **Watermark** (optional): subtle; don’t compete with on-screen Shorts text

---

## About & links

- [ ] **About description** (2–3 sentences): building Shorts systems in public + honest monetization education + founder lanes (Spark, Companion, book, lab)—**no fake earnings or “#1” claims**
- [ ] **Links:** add only what is live (website, repo, newsletter, beta)—use “coming soon” in copy, not dead URLs
- [ ] **Contact / business email** if you take sponsors (separate from personal if needed)
- [ ] **Default upload language** and caption language set correctly

---

## Shorts & content organization

- [ ] **Channel trailer** (optional): one Short or 30s cut explaining *process proof, not bank flex*—or skip until you have 5+ published Shorts
- [ ] **Shorts shelf** on channel homepage: pin 3–5 best **intent** Shorts (monetization literacy + one series entry)
- [ ] **Playlists** (create even if sparse; add videos as you publish):

  | Playlist | Purpose |
  | --- | --- |
  | Shorts Money / Monetization literacy | Policy, views vs revenue, CTA patterns |
  | Spark Lab | Dating app build log (pt order) |
  | Companion Build | iPhone companion avatar build |
  | One Insight, One Page | Book / psychology chapter tests |
  | Robot Face R&D | Lab notes (B2B expressions) |
  | Creator Shelf | Platform / creator economics (design) |

- [ ] **Featured sections** on homepage: “Popular Shorts” or a single playlist per lane—rotate after [`analytics/WEEKLY-REVIEW.md`](../analytics/WEEKLY-REVIEW.md)

---

## Upload defaults (Studio)

- [ ] **Category:** Education or How-to (match majority of Shorts)
- [ ] **Audience:** “No, it’s not made for kids” unless content is kids-directed
- [ ] **Altered / synthetic content** disclosure workflow understood for AI voice, avatars, or heavy generative B-roll
- [ ] **Default license:** Standard YouTube license unless you need Creative Commons for a specific series
- [ ] **Shorts remixing** preference set (allow/disallow) per your comfort with re-use

---

## Monetization & compliance (when eligible)

- [ ] **YouTube Partner Program:** check current eligibility in Studio—do not reference dollar thresholds in public copy unless you paste official Help text
- [ ] **Ad-friendly self-check** habit linked to [`content/scripts/3-second-monetization-check.md`](../content/scripts/3-second-monetization-check.md)
- [ ] **Paid promotion** toggle understood for sponsors
- [ ] **Affiliate / product links** policy: disclose on-screen + in description (see [`publish/DESCRIPTION-CTA.md`](../publish/DESCRIPTION-CTA.md))

---

## Community & engagement (if available)

- [ ] **Community tab** enabled (requires eligibility—if grayed out, skip and use pinned comments + Shorts comments only)
- [ ] First Community post draft: *what this channel is / isn’t* (education, not financial advice; no income cosplay)
- [ ] **Comment moderation:** hold potentially inappropriate comments for review if you use keyword CTAs (reduces spam visibility)
- [ ] **Pinned comment workflow:** template saved from [`publish/DESCRIPTION-CTA.md`](../publish/DESCRIPTION-CTA.md)

---

## Pre–first publish smoke test

- [ ] Upload one **unlisted** Short; confirm vertical preview, captions, and `#Shorts` behavior
- [ ] Open channel in **incognito** on mobile: profile, About, one public Short, playlist empty state OK
- [ ] Copy channel URL into [`monetization/OFFER-MAP.md`](../monetization/OFFER-MAP.md) placeholder rows when ready
